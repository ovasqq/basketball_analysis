1. Что сделано

- Калибровка корта по кадру: пиксель ↔ метры на площадке, вид сверху, подсветка разметки FIBA
- Инструмент ручной разметки точек калибровки
- Из открытых проектов перенесены 3 сети для автокалибровки: KaliCalib, YOLOv8-pose (18 точек), Roboflow (33 точки); способ выбирается флагом
- Сравнение на тестовом кадре: KaliCalib попадает в разметку (12–45 px), две другие нет (обучены на телетрансляциях NBA)
- Документ по архитектурам и обучению сетей, план дообучения
- Требования к детектору мяча для команды трекинга (формат, поля)
- Подход к подсветке разметки без наложения на игроков и мяч

1) сделано построение гомографии между кортом и изображением по ключевым точкам + калибровка с помощью ransac. 
2) поддерживает нанесение разметки FIBA на исходное изображение
keypoints можно ставить вручную, можно с помощью сеток: KaliCalib (93 keypoints), YOLOv8-pose (18 keypoints), Roboflow'ловская сетка (33 keypoints). первая сетка было обучена на deepsport датасете, другие - на трансляциях профессиональных матчей.

3) сглаживать

- Первая «площадка матча»: игроки на схеме корта, мини-карта и файл с позициями
- Согласовать формат и синхронизацию с командой трекинга мяча

3. Блокеры

- Нет реальных видео с целевых камер, проверено на одном кадре
- Неясно, как будут снимать пользователи (камера / телефон, ракурс)
- Не определён формат результата и обмена данными с командой мяча
- Нет GPU для дообучения
- Лицензии: ultralytics — AGPL, датасет KaliCalib — некоммерческий
