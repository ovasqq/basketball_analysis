1. Что сделано

1) сделано построение гомографии между кортом и изображением по ключевым точкам + ransac для стабильности
2) сделано нанесение FIBA-подобной разметки на исходное изображение
3) сделан фикс дисторсии, чтоб не портилась проективность задачи
4) keypoints для гомографии можно ставить вручную, можно с помощью сеток: KaliCalib (91 keypoints), YOLOv8-pose (18 keypoints), Roboflow'ловская сетка (33 keypoints). первая сетка была обучена на deepsport датасете, другие - на трансляциях профессиональных матчей.
5) для теста прикручена предобученная yolo для детекции игроков и их позиций на площадке
6) реализована обработка видео со статичной камеры - рисуется разметка + позиции игроков на виде сверху. быстренько прогнал на видео любительской игры из датасета SportCenter (EPFL). в итоге весь пайплайн занимает 50 мс на кадр (на M5)
